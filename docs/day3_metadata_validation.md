

*# Day 3 - Hyperspectral Data and Metadata Validation*



*## Objective*

*Validate hyperspectral image data and crop metadata*

*in the TerraSpectra platform.*



*## Work Completed*

*- Loaded hyperspectral data from HDF5.*

*- Extracted crop metadata.*

*- Validated image dimensions.*

*- Checked spectral band count.*

*- Validated wavelength information.*

*- Checked healthy and stressed labels.*

*- Validated scanning method.*

*- Generated a validation report.*



*## Dataset Information*

*- Crop: Tomato (sample metadata)*

*- Image size: 128 x 128*

*- Spectral bands: 224*

*- Wavelength range: 400-1000 nm*

*- Scanning method: Hyperspectral Imaging*

*- Classes: Healthy (0), Stressed (1)*



*## Validation Results*

*- Image dimensions: Valid*

*- Spectral bands: Valid*

*- Wavelengths: Valid*

*- Labels: Valid*

*- Crop metadata: Valid*

*- Sensor metadata: Valid*



*## Outcome*

*TerraSpectra can now load and validate*

*hyperspectral data along with its crop metadata.*



*Note: The current dataset is synthetic and has*

*not been validated using real farm measurements.*
